# PDF to Tree 取扱説明書

### 概要
* ソフト名 : PDF to TreeText
* 開発者 : Terry（ブログ：https://kennyterry.hatenablog.com）
* 動作環境 : Windows 10, Windows 11
* 種別 : フリーソフト
* * *
### はじめに
1. 『PDF to TreeText』はフリーソフトです。どなたでもダウンロード、再配布してご使用いただけます。
2. 『PDF to TreeText』を使用することにより生ずるいかなる問題も開発者は責任を負いません。

***
### 紹介
本ソフトウェアは、PDFファイルの「しおり（ブックマーク）」を解析し、階層化されたテキストファイル（TreeText 形式）として抽出・出力するユーティリティです。
* 画像が含まれている場合、サブフォルダに保存し文書内にリンクタグを埋め込みます。
* リンクタグを NanaTerry に合わせた場合、プレーンテキストモードでも「Ctrl + Click でローカル画像表示ポップアップ」出来るようになります。


※2023/04/20 に公開した [Python 版](https://kennyterry.hatenablog.com/entry/edeaec872bdda59f984fe1f7dbb5cd9c)とファイル名は同じですが一から作り直した別物です。

***
### 動作環境
Windows 10、Windows 11、Windows 7 （64bit）での動作を確認しています。
32bit版 でも動作すると思います

***
### インストール
ダウンロードした zip ファイルを適当なフォルダに展開してください。 
zip 内に同梱されている `PDF2Tree.exe` と `pdfium.dll` は、必ず同じフォルダに配置した状態で使用してください。

***
### 使い方
1. 以下のいずれかの方法で PDF を読み込む。
    *  PDF ファイルを本ソフトの画面にドラッグ＆ドロップする。
    *  画面上の「開く」アイコンをクリックする。
    *  メニューバーから「ファイル」→「開く」を選択する（ショートカットキー：`Ctrl + O`）。
※パスワードで保護されたPDFを開いた場合、パスワードの入力画面が表示される。正しいパスワードを入力すると読み込みが開始される。

2. 階層化テキストを出力する
    *  PDF を読み込み、左側にツリー（目次）が表示されたら、以下のいずれかの方法でテキストファイルとして保存する。
    *  画面上の「エクスポート」アイコンをクリックする。
    *  メニューバーから「ファイル」→「出力」を選択する（ショートカットキー：`Ctrl + Enter`）。

3. 設定（画像リンクタグの形式）
    *  設定画面から、抽出した画像をテキスト内に埋め込む際の「タグの形式」を変更できる。
    *  【 Markdown 方式】: `![画像名](パス)` の形式。一般的な Markdown エディタ向け。
    *  【 独自タグ方式 】: `<nlink>パス</nlink>` などの形式。NanaTerry 等の特定エディタ向け。


### 階層化テキストを NanaTerry で読み込む方へ

* 【独自タグ方式】を選択して、PDF2Tree のタグを NanaTerry 側の「設定」「リンク」「デフォルトリンクタグ」に合わせてください。
* 「設定」「画像」「リンクタグを Ctrl + Click でローカル画像表示ポップアップ」にチェックしてください。

### 仕様と制限事項（必ずお読みください）
本ソフトは PDF の内部データを解析してテキスト化するため、見た目とは異なる結果になる場合があります。
以下の仕様を理解した上で利用してください。。

#### 抽出の基本仕様
*   ビューワ機能は最小限: 右画面に PDF の内容が表示されるますが、これは確認用の簡易表示であり、高度な閲覧機能は持ちません。
*   ツリーが表示されない場合: 読み込んだ PDF 自体に「しおり（目次データ）」が設定されていない、またはデータが破損している場合、ツリーは表示されず抽出もできません。
*   ヘッダ・フッタの位置: ページ番号や上部のタイトル（ヘッダ・フッタ）が、本文の「一番最初」に抽出されることがあります。これはPDF作成ソフトが「本文より先にページ番号を描画する」という内部構造になっているためであり、異常ではありません。
*   行頭ピリオドの自動変換: 抽出したテキストの行頭に半角ピリオド `.` がある場合、自動的に全角の `．` に変換されます。これは、出力先の TreeText 形式において、半角ピリオドが「階層の区切り」として誤認識され、構造が破壊されるのを防ぐための安全措置です。

#### しおり（目次）が同じページに複数ある場合の挙動
*  1ページの中に複数のしおりが存在する場合、読みやすさを考慮して以下のようにテキストを振り分けます。
    *  親項目と子項目: 「第1章」と「1節」が同じページにある場合、本文はすべて「1節」の中に格納され、「第1章」は空のフォルダとして出力されます。
    *  同列の項目: 「1節」と「2節」が同じページにある場合、本文はすべて先の「1節」に格納され、「2節」は空になります。

#### 画像抽出の仕様
PDF 内の画像は、ページの状態によって抽出方法が自動的に切り替わります。
*   テキストが含まれるページ: 本文テキストを抽出した後、ページ内に存在する「意味のあるサイズの画像（写真など）」だけを個別に抽出し、テキストの末尾にタグとして挿入する。
*   画像のみのページ（漫画やスキャン書籍など）: テキストが存在しないページは、ページ全体を「1枚の画像」として撮影（レンダリング）し、その画像タグのみを出力する。
*  PDF 作成ツールで巨大な画像を埋め込む際、メモリ節約のために画像を帯状（タイル状）に細かく分割して保存する仕様を持っているときがあります。その理由から本ソフトでは小さすぎる画像と判断して出力しない場合があります。
*  特に Windows の「Microsoft Print to PDF」がその仕様なのですが、ページに画像しか存在しない場合は前述したようにそのタイルのピースをつなぎ合わせて一枚の画像として出力しますが、文章と共に画像のピースがあるときは、検出出来ない場合があります。

#### 読み込めない・文字化けする PDF について
以下の PDF は、テキストの抽出が不可能です。
*   特殊なフォント・文字コード: PDF 作成ソフトの仕様により、文字コード（ ToUnicode テーブル）が破損している、または特殊な暗号化フォントが使われている場合、文字化けや空白になる。ファイル自体の破損によるエラーが表示されることもある。

#### 階層化テキストは UTF8 で保存されます。

### アンインストール
インストールしたフォルダごと削除してください。

## 使用しているライブラリなど
「pdfium.dll」は Google Chrome 等でも使用されているオープンソースの PDF レンダリングエンジンです。
本ソフトは、32bit アプリなので DLL も 32bit版（64bit版と同名ファイル）を使用しています。

上記 DLL を Delphi 用にインポートしたライブラリ [PdfiumLib](https://github.com/ahausladen/PdfiumLib) を使用しています。
